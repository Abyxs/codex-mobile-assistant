# 最新版本说明

Windows **1.6.21**，Android / iOS **1.0.17**（手机内部构建号 18）。

## 本次更新

- 苹果端下载列表按钮改为“用其他应用打开”。
- 点击后弹出 iOS 系统分享菜单，可选择其他应用，也可选择“存储到文件”。
- 旧下载记录同步显示新的操作提示；关闭菜单后文件仍保存在 App 内。
- 兼容 iPhone 与 iPad 的系统菜单显示方式。
- 保留文件定位、长按查看路径、圆环下载进度和最新下载置顶。

电脑端和手机端请配套更新，新的按钮文案由电脑端提供。

## 验证范围

三个平台已构建完成，安装包完整性与版本已核对。苹果端新的系统菜单交互尚未做真机验证。
