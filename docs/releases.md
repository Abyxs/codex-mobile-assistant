# 最新版本说明

Windows **1.6.20**，Android / iOS **1.0.16**（手机内部构建号 17）。

## 本次更新

- 点击对话文件链接，打开所在文件夹并定位、高亮文件。
- 长按文件链接显示完整路径，支持复制。
- 通过文件页下载按钮下载，保留圆环进度与最新下载置顶。
- 图片继续支持点开预览与双指缩放。
- iOS 文件请求进入下载流程，避免把文件打开失败显示成主页面断线。

## 已有主要功能

Windows 双模式连接，手机扫码、保存地址与自动连接；同步对话、新建临时对话、模型及推理强度选择、技能选择、任务确认、项目文件上传与下载。

## 验证范围

三个平台已构建成功，安装包完整性与版本已核对。最新文件定位和长按交互尚未做真机验证。电脑端与手机端请配套更新。

所有安装包以 [GitHub Releases](https://github.com/Abyxs/codex-mobile-assistant/releases/latest) 提供的文件为准。
