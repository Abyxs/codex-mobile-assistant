# 最新版本说明

Windows **1.6.24**，Android / iOS **1.0.20**（手机内部构建号 21）。

## 本次更新

- 输入框支持普通文件附件：文档、表格、代码和压缩包等不再按扩展名过滤，支持选择、粘贴和拖入。
- 上传显示进度，文件卡片显示名称、大小及上传状态。每条消息最多 4 个附件（含图片），普通文件单个最大 20 MB；目前普通文件仅支持电脑本地对话，SSH 对话保留图片支持。
- 确认卡片默认展示操作说明，完整命令、工作目录和权限等信息折叠展示，可以展开、复制详情。
- 新增“只读”“默认权限”“完全访问”三个权限选项，仅作用于当前对话的下一轮；已有待确认操作仍需单独处理。完全访问会自动通过后续操作审批，并允许访问项目外文件。
- 保留文件定位、圆环下载进度、最新下载置顶，以及苹果端已下载文件的“用其他应用打开”。

电脑端和手机端请配套更新，对话与文件页面由电脑端提供。IPA 为未签名包，需要自行签名后安装。

## 验证范围
