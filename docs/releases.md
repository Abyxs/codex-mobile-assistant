# 最新版本说明

Windows **1.6.23**，Android / iOS **1.0.19**（手机内部构建号 20）。

## 本次更新

- 点击对话中的文件链接，先打开文件列表并定位文件；点击文件旁的下载按钮才开始下载。
- 读取文件列表时显示加载提示；修正手机端将对话文件链接直接加入下载的旧逻辑。
- 下载完成后，苹果端在项目文件列表点击文件名或右侧“用其他应用打开”，直接弹出系统分享菜单，不再默认重新下载。
- 下载列表中的分享入口继续保留；Android 和网页沿用各自的保存方式。
- 保留文件定位、长按查看路径、圆环下载进度和最新下载置顶。

电脑端和手机端请配套更新，文件列表的交互由电脑端提供。
